# Расширенный аудит игры

Обычные регрессии и Release audit остаются включены. Workflow Deep game audit запускается при PR, по субботам и вручную.

## Наборы

- По 1024 действия в Chromium, WebKit и Firefox: два seed по 512 действий. Движение, прыжок, кормление, формы, бомбы, постановка предметов, камера, посадка/спрыгивание, меню, пауза и активное торнадо. Карты меняются через 64 действия.
- Сочетания: движение + бомба + постановка; пауза + фитиль; пауза + активное торнадо; смена карты с бомбой; длинные кадры; сон + бомба + форма + пробуждение; горящий дом + торнадо и отмена.
- Первое появление объектов на семи картах: время подготовки и CPU-время кадров. Абсолютный FPS программного рендеринга CI не равен FPS телефона.
- Поворот экрана, портретные меню, испорченный JSON сохранений и недоступная таблица рекордов.
- 2000 воспроизводимых проб внутренних областей препятствий для трёх размеров тела и проверка освобождения после контакта.
- 30 реальных минут в одной странице Chromium: действия, смена карт, восстановление после игровых смертей и сравнение ресурсов одинаковых карт. Ручной запуск поддерживает 30–60 минут. Это не ускоренное моделирование.
- Три мутации во временной копии: отключение освобождения ресурсов, столкновений и лимита существ. Сначала проходят исходные тесты; каждый мутант обязан вызвать падение теста, а не синтаксическую ошибку. Публикуемый код не изменяется.

## Повтор ошибки

Артефакты: report.json, actions.jsonl, скриншот, Playwright trace последних действий и видео при ошибке. Журнал содержит SHA, движок, seed, каждое действие и состояние. Видео длинной сессии можно сопоставить с временными отметками журнала. Успешные видео удаляются; артефакты хранятся семь дней.

Повтор: тот же commit, браузер и AUDIT_SEED, затем node scripts/deep-audit-browser.mjs. Для Firefox нужен виртуальный экран, как в workflow. План действий воспроизводим; внешние кадры и драйвер могут отличаться.

Наблюдатель проверяет координаты и счётчики, лимит 16, лимит двух питомцев, несовместимые формы, полёт только на острове и таймеры бомб. Ресурсы сравниваются между посещениями одной карты после прогрева; это не измерение памяти в байтах.

## Границы

CI не заменяет настоящий слабый Android, iPhone, нагрев, фоновые ограничения ОС и реальные одновременные касания. Случайные действия не доказывают достижимость каждого задания при любой пользовательской постройке. Запросы рекордов перехвачены: тестовые очки не отправляются в настоящую таблицу. Офлайн-обновления проверяет существующий module-browser.mjs.
