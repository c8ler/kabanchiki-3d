# Проверка движения кабанчиков

`npm test` запускает все файлы tests/*.mjs, включая регрессии переходов.
`npm run validate` проверяет существующие требования игры.

Браузерный робот:
```sh
npm install --no-save --package-lock=false playwright@1.56.1
npx playwright install chromium webkit
python3 -m http.server 8080
# В другом терминале:
node scripts/boar-robot-browser.mjs
BROWSER=webkit node scripts/boar-robot-browser.mjs
ROBOT_SEED=209 node scripts/boar-robot-browser.mjs
```

GitHub Actions запускает робот на pull request, при push в main и каждый
понедельник в 04:23 UTC. Ручной запуск позволяет указать seed для повторения
сбоя. Артефакты boar-robot-chromium и boar-robot-webkit содержат JSON с seed,
локацией, сезоном, FPS, началом и целью маршрута, числом кадров и перепланирований.
При обнаружении ошибки сохраняется снимок экрана.

Chromium проверяет шесть локаций и четыре сезона при 30 FPS, летние маршруты
при 60 FPS; WebKit проверяет шесть летних локаций в мобильном окне.
Оба проверяют пять закрытых выходов с другом и со вспомогательным кабанчиком.
Бот вызывает настоящие функции движения и столкновений в браузере.
Это симуляция движения с фиксированным шагом, а не измерение производительности
и не полное прохождение квестов через нажатия клавиш. Случайная генерация мира
в игре пока не фиксируется seed: seed воспроизводит выбор целей в текущем мире.

Приёмка требует отсутствия проникновений, конечной высоты, достижения цели
и фактического завершения разрушения преграды. Отдельная регрессия многократно
проверяет абсолютную высоту вспомогательного кабанчика на склоне, полу, мосту
и в воде при 15/30/60/144 FPS.

Робот не гарантирует отсутствие всех багов: бой, толпа, погода, прыжки всадника
и полный квестовый цикл также требуют существующих тестов и ручной игры.
