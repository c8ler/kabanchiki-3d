# Кабанчики 3D v71 — Character Remaster

Первый этап технического ремастера выполнен без переписывания игровой механики.

## Новая структура
- `index.html` — интерфейс и загрузка.
- `src/game.js` — существующая рабочая игровая логика, вынесенная из HTML.
- `src/assets.js` — единый реестр будущих моделей/текстур/звуков.
- `levels/levels.js` — метаданные пяти локаций.
- `assets/models`, `assets/textures`, `assets/sounds` — места для ремастер-ассетов.
- `tests/` — контракт игровых функций.
- `scripts/` — автоматические проверки и визуальный smoke-test.
- `.github/workflows/` — облачная проверка GitHub Actions.

## Почему не разбито сразу на 20 JS-файлов
Сначала вынесен весь рабочий модуль целиком. Это уменьшает риск сломать связи между механиками.
Дальше подсистемы будут переноситься по одной с автоматической проверкой после каждого шага.

## Следующий этап
Visual Remaster #1: новый лес — освещение, тени, растительность, земля, камни и атмосфера,
при сохранении текущих механик и производительности телефона.


## Visual Remaster #1 — Forest (v68)
- Более кинематографичная цветопередача ACES.
- Мягкие динамические тени на ПК; облегчённый режим на телефоне.
- Сотни травинок через InstancedMesh без сотен отдельных draw calls.
- Полевые цветы, папоротники и упавшие брёвна.
- Солнечный диск, более глубокий лесной свет и дальний туман.
- Декоративный слой леса отделён от коллизий, поэтому новая трава не мешает Тимуру и кабанчикам.
- Ремастер-слой виден только на первой локации.


## v69 — Forest World
- Деревья получили многогранные стволы, корни, ветви и нерегулярные кроны вместо стопок кубов.
- Дорожка стала неровной по ширине, получила тёмную кромку и мелкие камни.
- Земля получила пятна мха и более тёмной травы.
- Декоративный слой автоматически отключается вне лесной карты.
- Сохранены старые координаты деревьев и радиусы коллизий, чтобы не ломать геймплей.


## v71 — Character Remaster
- Тимур: дополнительные волосы, уши, глаза, рюкзак и обувь.
- Кабанчики: объёмные уши, небольшие клыки, копыта и анимированный хвост.
- Детали добавлены поверх существующих моделей: AI, бой и коллизии сохранены.
- Тени персонажей включены в desktop-профиле, мобильный профиль остаётся облегчённым.


## v76 — яблоки на деревьях
- Яблоки больше не появляются на земле.
- Яблоки растут на доступных деревьях на высоте и требуют прыжка для сбора.
- Грибы, капуста и ягоды остаются наземными.


## v77 Collision Lab
Unified solid collision for trees/branches, rocks, mountains and lair obstacles; automatic depenetration and sliding; runtime collision audit exposed as `window.__KABANCHIKI_COLLISION_AUDIT__()`.
